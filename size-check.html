Только статические файлы. Без расписания, API, подписок и push. Файлы одинаковы на трёх тестах. Ничего не отправляется на сторонние сервисы.

Нажмите кнопку. Максимум 45 секунд на файл. Сначала 1 КиБ, затем 256 КиБ.

«ПОЛНОСТЬ ПОДТВЕРЖДЕНА» означает: совпали число байтов и SHA-256. Появление этой страницы само по себе не подтверждает загрузку файлов.

При ошибке сохраните скриншот. Один результат не устанавливает причину сбоя. Для сравнения повторите на другой сети, оставаясь без VPN.
